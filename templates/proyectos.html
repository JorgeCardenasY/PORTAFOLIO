  • Proyecto 1: Script para la Obtención de Datos abiertos de MercadoPúblico

    Este proyecto es un desarrollo en Python que accede a los datos abiertos de MercadoPúblico y descarga datos en formato ZIP correspondientes a Licitaciones, Compras Ágiles y Órdenes de Compra en un rango de años y meses seleccionados. Cada descarga es descromprimida a CSV según su tipo (Licitaciones, Compras Ágiles y Órdenes de Compra). Alternativamente, se puede cargar estos datos a una base de datos PostgreSQL.
    En un proceso ETL correspondería a la fase de extracción de datos para su ingesta, transformación y análisis.

  • Proyecto 3: Aplicación Web con Django e integración PostgreSQL.

    Este portafolio es una aplicación web construida con Django, que permite a los usuarios registrarse, autenticarse y exhibir sus proyectos. El backend, en Python, utiliza SQLite para desarrollo y la librería Pillow para gestionar imágenes. El frontend emplea las plantillas de Django, se estiliza con Tailwind CSS para una interfaz responsiva y usa JavaScript vanilla para la interactividad. La seguridad es prioritaria, aprovechando las protecciones nativas de Django: middleware contra CSRF y clickjacking, un sistema robusto de autenticación que hashea contraseñas, validadores para garantizar contraseñas robustas y cabeceras de seguridad HTTP. La clave secreta se gestiona como variable de entorno en producción.

    Ver en GitHub Más Detalles

  • Proyecto 4: Aplicación web para Centro de Padres

    Este proyecto es una aplicación web desarrollada con Django para la gestión de un centro de padres. Actualmente se encuentra en desarrollo y tiene como objetivo facilitar la administración del control de cuentas relacionadas a los miembros del centro de padres y apoderados (Usuarios etiquetados como Apoderados dentr del sistema). Se espera poder escalarlo para, potencialmente, a futuro, podere fectuar la gestión y coordinación de ctividades, eventos y comunicaciones entre los miembros del centro de padres.
    La aplicación cuenta con funcionalidad de registro de usuarios, gestión de sesiones. Tal como ya ha sido mencionado, El proyecto podría incrementarse en el sentido de permitir la gestión de eventos, publicación de noticias y un sistema de mensajería interna.

    Claves de acceso a la plataforma
    Para ingresar a la plataforma, puedes utilizar las siguientes credenciales de prueba:
    SuperUsuario: root
    Contraseña: a4t5one3$
    Apoderado: 22722834
    ZZZZZZZZZZZContraseña: password123
    Ténga Usted presente que en general el Usuario Apoderado puede sólo visualizar y gestionar únicamente su propia información y no la de otros usuarios.
    Para la asignación de cargos (montos a pagar) se ha creado un atributo especial en el modelo de Usuario que permite asignar montos específicos a cada Apoderado. Este atributo se ha denominado 'registrar_pago', el cual opera de manera booleana, y quienes tienen valor 'True' tiene la facultad de ejercer el CRUD (Crear, Leer, Actualizar, Eliminar) sobre los cargos asignados a los Apoderados. Es relevante mencionar que , además, el Usuario SuperUsuario tiene acceso completo a todas las funcionalidades y datos dentro de la plataforma. Cabe señar que estas credenciales son únicamente para fines de prueba y demostración. Se recomienda no utilizarlas en un entorno de producción real por razones de seguridad.
